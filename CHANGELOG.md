# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект использует [семантическое версионирование](https://semver.org/lang/ru/).

## [0.2.0] — 2026-08-20

### Добавлено

- Поддержка исходных файлов `.avi` и `.webm`. Перекодированный результат для них сохраняется в `.mp4`,
  потому что эти контейнеры не рассчитаны на HEVC или AV1 со звуком AAC; режим «Только обрезать»
  сохраняет исходный контейнер.
- Кнопка **«Показать в папке»** на экране результата — открывает Проводник с выделенным файлом.
- Индикатор хода операции на кнопке приложения в панели задач Windows.
- Окно запоминает свой размер и состояние «развёрнуто» между запусками.
- Зона перетаскивания на стартовом экране подсвечивается, когда над окном тащат файл.

### Изменено

- **Одновременно работает только один экземпляр.** Выбор нескольких файлов в Проводнике больше не
  запускает несколько окон: второй запуск передаёт файл в уже открытое окно и выводит его на передний план.
- Сжатие начинается заметно быстрее: кодировщик определяется один раз за сессию, перебор
  останавливается на первом рабочем, а проба выполняется заранее при запуске приложения.
- Кадры для таймлайна готовятся по ключевым кадрам — для десятиминутного ролика 1080p это 3 секунды
  вместо 18. Если ключевых кадров в файле мало, выполняется полное декодирование.
- Крупнее шрифты и элементы на всех экранах, экраны заполняются целиком.
- Система не уходит в сон, пока идёт кодирование.

### Исправлено

- Повреждённый `settings.json` больше не стирает настройки молча: файл сохраняется рядом,
  а на странице настроек появляется сообщение с путём к нему.
- Смена языка сообщает, что интерфейс переключится после перезапуска.
- Кэш кадров ограничен последними 24 видео — раньше он рос без ограничений.
- Устранена утечка объектов синхронизации при подготовке кадров.
- Ошибка удаления временного файла больше не подменяет исходную ошибку операции.

## [0.1.0] — 2026-08-09

- Первый публичный выпуск: сжатие, обрезка с перекодированием, обрезка без перекодирования,
  интеграция с Проводником, установщик и Portable-версия.
