# FFmpeg used by Clipora

Clipora runs **FFmpeg 8.1.2 / FFprobe** as separate local child processes. Runtime binaries are included in Setup and Portable packages, so users do not install FFmpeg separately.

- Build: BtbN `ffmpeg-n8.1.2-34-g9b6c8969e0-win64-lgpl-8.1`
- License: **LGPL-3.0-or-later**
- Architecture: Windows x64, static executables
- FFmpeg commit: [9b6c8969e0](https://github.com/FFmpeg/FFmpeg/commit/9b6c8969e05b4f0b29f0f85cd501be6b3e582e6b)
- Build scripts: [2437e7b868](https://github.com/BtbN/FFmpeg-Builds/commit/2437e7b868da3c11872367b15f3c613b87c24819)

Binary hashes, the immutable archive URL and source archive hashes are recorded in [PROVENANCE.json](PROVENANCE.json). Source availability is documented in [SOURCE.md](SOURCE.md).
